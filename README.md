# CSE470-CAMPUS.CONNECT.PRO_PROJECT
Campus Connect Pro is a Laravel-based academic collaboration platform designed to facilitate seamless resource sharing within the university ecosystem. It enables students to access study materials while incorporating a structured faculty review and feedback mechanism. 


A unified campus lifestyle platform for university students.

# Tech Stack
- Backend: Laravel (PHP) + MySQL
- Frontend: Blade + Tailwind CSS + Vanilla JS
- APIs: Google Maps API, SMS API

# Setup Instructions
1. Clone the repo
2. Run `composer install`
3. Copy `.env.example` to `.env`
4. Set DB credentials in `.env`
5. Run `php artisan key:generate`
6. Run `php artisan migrate`
7. Run `php artisan serve`
